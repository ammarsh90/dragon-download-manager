# دليل Dragon Download Manager

## تحميل ملف

اضغط Add URL أو Ctrl+N. ألصق رابط HTTP أو HTTPS مباشرًا. حدد الاسم الكامل في Save as، ويمكنك إضافة وصف واختيار عدد الاتصالات. اضغط Start download، أو Download later لإضافته دون البدء.

نافذة التقدم مستقلة: تعرض الحالة والحجم والمنزل والسرعة والوقت المتبقي وتقدم كل اتصال. يمكن تغيير Speed limit بالكيلوبايت الثنائي في الثانية؛ القيمة صفر تعني دون حد. Pause يحفظ الأجزاء. Resume يكمل عندما يسمح الخادم. Background يغلق هذه النافذة ويبقي التنزيل في القائمة. يمكنك فتحها مجددًا بالنقر المزدوج على تنزيل غير مكتمل.

بعد الاكتمال استخدم Open file أو Open folder. النقر المزدوج على ملف مكتمل يفتحه.

## تكرار الاسم

إذا كان الاسم مستخدمًا، اختر الاحتفاظ بالملفين باسم مرقم، أو تغيير الاسم، أو استبدال الملف الموجود. إذا كان هناك تنزيل جارٍ بالاسم نفسه، يمكنك إظهار نافذته؛ لا يسمح بتحميلين جاريين يكتبان إلى الاسم نفسه. الاستبدال يحافظ على الملف القديم حتى نجاح حفظ الجديد.

## القائمة والطابور

التصنيفات على اليسار ترشح الملفات حسب الحالة أو النوع. البحث يشمل الاسم والرابط والوصف. Start queue يبدأ التنزيلات المنتظرة وفق الحد المحدد في Options. Stop all يوقف التنزيلات الجارية والمنتظرة مؤقتًا. Scheduler يحدد بدء الطابور في وقت لاحق، مع ضرورة إبقاء التطبيق مفتوحًا.

يمكن إزالة عناصر من السجل دون حذف الملف المكتمل. استخدم Rename للملفات التي لم يبدأ تنزيلها أو الملفات المكتملة؛ التنزيل الجزئي لا يدعم نقل هويته إلى اسم جديد حاليًا.

## الاستكمال والاتصالات

عدد الاتصالات حد أقصى، وليس وعدًا بسرعة معينة. يعتمد استخدام الأجزاء على دعم الخادم للنطاقات ووجود معرف ثابت للنسخة. الملفات الصغيرة تستخدم عددًا أقل. إذا تجاهل الخادم التقسيم، يستخدم اتصالًا واحدًا. إذا تغيرت النسخة البعيدة أو غاب التحقق، يبدأ من جديد بدل خلط بيانات ملفين مختلفين.

الأجزاء محفوظة في مجلد بيانات التطبيق، خارج مجلد الحفظ النهائي. احرص على مساحة تكفي للأجزاء ولنسخة الملف النهائية أثناء التجميع. إغلاق التطبيق يحتفظ بالأجزاء؛ إزالة العنصر من القائمة قد تتركها في مجلد البيانات.

## مشاكل شائعة

- صفحة HTML بدل الملف: استخدم رابط التنزيل المباشر.
- رفض الوصول أو 403: الرابط قد انتهى أو يحتاج جلسة متصفح؛ تكامل المتصفح الكامل لم يُنجز بعد.
- خطأ حفظ: تحقق من صلاحيات المجلد والمساحة الحرة وعدم حجز الملف بواسطة برنامج آخر.
- لا توجد عدة اتصالات: الخادم قد لا يدعمها أو الملف صغير أو لا يوفر معرف نسخة يمكن التحقق منه.
- الاستكمال بدأ من الصفر: هوية الملف تغيرت، أو الخادم لا يسمح بالاستكمال الآمن.

## واجهة مضغوطة والإغلاق بجانب الساعة — 1.2.1

نافذة التحميل أصغر افتراضيًا؛ استخدم Show details لعرض الاتصالات وHide details لإخفائها. الروابط والأسماء الطويلة مختصرة بصريًا، ويمكن رؤية النص الكامل عند تمرير المؤشر. محدد السرعة حقل صغير. الألوان محايدة، مع تحديد أزرق هادئ وهوية Dragon في الأيقونة.

زر × في النافذة الرئيسية يخفي البرنامج في منطقة الإشعارات بجانب الساعة ويستمر التنزيل. انقر أيقونة Dragon لإعادة إظهار النافذة، أو افتح قائمتها بزر الفأرة الأيمن. File → Exit Dragon ينهي البرنامج بالكامل. يمكن تعطيل البقاء بالخلفية من Options. إذا كانت منطقة الإشعارات غير متاحة، يبقى الإغلاق طبيعيًا. قد يضع Windows الأيقونة ضمن قائمة الأيقونات المخفية.

## التحميل من المتصفح — 1.3

راجع [دليل ربط المتصفحات](BROWSER_INTEGRATION.md). ثبت الإضافة مرة واحدة ثم فعّل Capture browser downloads. عند وصول الملف، يظهر فورم Dragon ويكون الملف محفوظًا في الطابور؛ Keep in queue يغلق الفورم مع إبقاء المهمة متوقفة.
