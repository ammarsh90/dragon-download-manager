# ربط Dragon بالمتصفحات — 1.3.0

## Chrome وEdge على Windows

1. أغلق النسخة القديمة من Dragon من **Exit Dragon**، ثم ثبّت الإصدار 1.3.0 أو أحدث.
2. افتح **Options → Browser integration → Open extension folder** في البرنامج.
3. افتح `chrome://extensions` أو `edge://extensions`، وفعّل Developer mode.
4. اختر Load unpacked وحدد مجلد `browser-extension/chromium` داخل مجلد تثبيت Dragon.
5. افتح أيقونة Dragon من شريط المتصفح. يجب أن تظهر Connected. فعّل Capture browser downloads واحفظ الإعدادات.

الإضافة المرفقة توزيع تطوير من GitHub؛ ليست منشورة في متجر Chrome أو Edge. يتطلب المتصفح تثبيتها يدويًا، ولا يفرض المثبّت تثبيتها أو يغيّر إعدادات المتصفح خفية. أبقِ المجلد في مكانه لأن الإضافة غير المعبأة تقرأ ملفاتها منه.

## النسخة المحمولة

فك أرشيف البرنامج في مكان ثابت، ثم شغّل `register-browser.ps1` الموجود بجانب `DragonBrowserHost.exe` باستخدام PowerShell. يسجل السكربت مفاتيح Dragon في حساب Windows الحالي فقط. لا حاجة لتسجيل مفاتيح ArrowDL أو تثبيت إضافته. إذا نقلت البرنامج فأعد التسجيل. لإلغاء التسجيل استخدم `-Unregister`؛ يحذف السكربت مفاتيح هذا المسار فقط.

المثبّت العادي يسجل وسيط الاتصال في HKLM لعملاء Chrome وEdge وFirefox. تسجيل النسخة المحمولة في HKCU قد تكون له أولوية، لذلك أزل تسجيل نسخة محمولة قديمة إذا كانت تشير إلى مسار لم يعد موجودًا.

## Firefox

يوجد مجلد `browser-extension/firefox`. يمكن تحميل `manifest.json` مؤقتًا من `about:debugging → This Firefox → Load Temporary Add-on`. تحتاج إعادة تحميله بعد إعادة تشغيل Firefox. التثبيت الدائم يتطلب توقيع Mozilla؛ لم يُنشر هذا الإصدار في متجر إضافات Firefox.

## ماذا يحدث عند الضغط على تحميل؟

- تراقب الإضافة طلبات HTTP/HTTPS وتلتقط تنزيلات GET المباشرة.
- توقف نسخة المتصفح مؤقتًا أثناء إرسال المعلومات إلى Dragon.
- يحفظ Dragon المهمة في الطابور كتابةً ذرية، ويرسل تأكيدًا برقم الطلب نفسه.
- بعد التأكيد فقط تلغي الإضافة نسخة المتصفح وتظهر نافذة معلومات الملف في Dragon.
- Start download يبدأ التنزيل، وDownload later أو Keep in queue يحتفظ بالمهمة متوقفة في قائمة البرنامج.
- إذا تعذر الاتصال أو حفظ المهمة، تحاول الإضافة استئناف تنزيل المتصفح وتعرض علامة تنبيه. راجع قائمة المتصفح إذا أوقفته أو ألغيته بنفسك أثناء النقل.

يمكن تعطيل Show file information before starting للبدء مباشرة بعد الاستلام. قائمة الزر الأيمن للروابط تبقى متاحة للإرسال اليدوي. جمع روابط الصفحة الموروث محفوظ في المصدر ويستخدم قناة Dragon الجديدة.

## الإعدادات

- **Capture browser downloads:** تشغيل الالتقاط التلقائي أو إيقافه.
- **Show file information:** إظهار فورم الاسم والمسار قبل بدء التحميل.
- **Use this download’s browser session:** إرسال ملفات الجلسة المطابقة لرابط التحميل إلى التطبيق المحلي فقط.
- **Excluded websites:** نطاق واحد في كل سطر؛ تشمل القاعدة النطاقات الفرعية.
- **Recover pending transfers:** معالجة عمليات نقل أوقفها إعادة تحميل الإضافة أو المتصفح.

## الجلسات والخصوصية

تُنقل ملفات الجلسة المطابقة لعنوان التنزيل، والمرجع واسم الملف وUser-Agent عبر Native Messaging إلى وسيط محلي، ثم عبر قناة خاصة بحساب Windows إلى Dragon. لكل مهمة cookie jar مستقل؛ لا تختلط جلسات المهام. لا تُحفظ ملفات الجلسة في JSON الطابور ولا تُطبع في السجلات. قد يحتاج تنزيل محمي بعد إعادة تشغيل Dragon إلى إرسال جديد من المتصفح لأن ملفات الجلسة غير محفوظة على القرص.

## حدود هذا الإصدار

طلبات POST وblob/data والتنزيلات الخاصة والتنزيلات التي حجبها المتصفح تبقى في المتصفح. الطلبات التي لا يمكن تحديد طريقتها بأمان لا تُلتقط تلقائيًا. لا يتضمن هذا تكاملًا عامًا مع جميع مشغلات الفيديو أو المحتوى المحمي، ولا ينقل رموز Authorization أو جلسات تسجيل الدخول التفاعلي. بعض مواقع التحميل قد لا تقبل إعادة طلب الرابط من برنامج خارجي.

عدد الأجزاء والاستكمال يعتمدان على الخادم كما في محرك Dragon. قد ينشأ ملف مكرر في حالات انقطاع نادرة أثناء تبادل التأكيد؛ رقم الطلب المحفوظ يحد من تكرار الاستلام. لا تستخدم نسختين مختلفتين من الإضافة أو مديرَي تحميل يلتقطان الملف نفسه في الوقت نفسه.

## المعرّفات

- Native host: `net.mobile_dragon.download_manager`
- Chrome / Edge development extension: `ipaiobelboggkilddbggbfgfocefefkm`
- Firefox development extension: `dragon-download-manager@mobile-dragon.net`

مفتاح Chromium العام مضمّن في manifest لتثبيت المعرّف بين مرات تثبيت نسخة التطوير. معرّف النشر المستقبلي عبر متجر رسمي قد يحتاج تحديث قائمة السماح في المثبّت.

## حالة التحقق

تم بناء وربط التطبيق ووسيط الاتصال، وفحص صياغة JavaScript وقراءة JSON ومطابقة معرّف الإضافة مع manifest الوسيط. لم تُشغّل اختبارات سلوكية أو تجربة شاملة في متصفح فعلي لهذه الجولة. الإصدار معاينة.
