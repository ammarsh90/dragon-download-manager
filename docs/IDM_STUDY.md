## تجربة الاستخدام المستهدفة

جدول الملفات هو مركز التطبيق، مع تصنيفات جانبية، وأوامر مسماة في الأعلى. إضافة ملف تعرض معلوماته ومسار الحفظ. لكل تحميل نافذة مستقلة تبين السرعة والوقت المتبقي والاستكمال وتقدم الاتصالات. فتح هذه النافذة لا يحجب بقية البرنامج.

| الميزة | الحالة في Dragon 1.2 | التفاصيل |
|---|---|---|
| شريط أدوات بأسماء واضحة | منفذة | إضافة، استكمال، إيقاف مؤقت، إيقاف الكل، حذف، مجلد، خيارات، طابور، جدولة |
| تصنيفات جانبية | منفذة | الكل، غير المكتمل، المكتمل، المنتظر، وأنواع الملفات |
| بحث في الملفات | منفذة | الاسم والرابط والوصف |
| فورم معلومات الملف | منفذة | رابط، اسم كامل ومسار، وصف، قراءة الحجم واسم الخادم، عدد الاتصالات، تنزيل الآن أو لاحقًا |
| نافذة تقدم مستقلة | منفذة | تقدم عام وتفاصيل كل اتصال، إيقاف واستكمال، فتح الملف والمجلد |
| تصغير طبيعي | منفذة | شريط مهام Windows، دون أيقونة قرب الساعة |
| أسماء مكررة | منفذة | اسم مرقم تلقائيًا أو تغيير يدوي أو استبدال آمن أو عرض التحميل الموجود |
| تنزيل متوازٍ | منفذة بشروط الخادم | حتى 16 نطاقًا، مع تخفيض العدد للملفات الصغيرة؛ لا يوجد وعد بزيادة سرعة كل خادم |
| استكمال بعد إعادة التشغيل | منفذة بشروط الخادم | نقاط حفظ دورية مع تحقق من حجم الملف وETag أو Last-Modified |
| الرجوع لاتصال واحد | منفذة | عند تجاهل الخادم Range؛ يمنع إلحاق جسم كامل بملف جزئي |
| إعادة محاولة الاتصال | منفذة | ثلاث محاولات للأجزاء القابلة للاستكمال مع الاحتفاظ بالبيانات |
| حفظ آمن للملف النهائي | منفذة | استبدال ذري بعد انتهاء التجميع؛ تبقى النسخة القديمة حتى نجاحه |
| بدء وإيقاف الطابور | منفذة | يحترم حد التنزيلات المتزامنة |
| جدولة أساسية | منفذة جزئيًا | بدء الطابور في وقت محدد أثناء تشغيل التطبيق |
| تقسيم ديناميكي وإعادة توزيع الأجزاء | غير منفذة | الإصدار الحالي يستخدم نطاقات ثابتة؛ يختلف عن خوارزمية IDM الديناميكية |
| محدد سرعة لكل ملف | منفذة | قراءة محدودة لكل اتصالات الملف مع مخازن شبكة محدودة؛ تعديل مباشر من نافذة التقدم |
| تحديث الروابط المنتهية مع إبقاء الأجزاء | غير منفذة | يحتاج تحققًا آمنًا من هوية الملف الجديد |
| تكامل متصفح بمستوى IDM | غير مكتمل | كود الإضافة الموروث موجود، ويحتاج إصدارًا وتحققًا منفصلين |
| التقاط الفيديو من جميع المواقع | غير مضمون | لا يوجد ادعاء بدعم كل مشغل أو موقع أو محتوى محمي |
| فئات مخصصة ومجلد لكل فئة | غير منفذة | التصنيفات الحالية تعتمد على امتداد الملف |
| جدولة دورية وإيقاف الجهاز | غير منفذة | لا توجد إجراءات طاقة تلقائية |

## مواصفات التصميم المنفذة

- واجهة Windows مكتبية واضحة، بهوية Dragon الذهبية والسوداء.
- خلفيات فاتحة افتراضيًا، ونمط داكن اختياري؛ النصوص والحقول والقوائم لها ألوان متوافقة.
- التصنيفات بعرض مستقل، والبحث فوق الجدول، دون إخفاء وظائف التنزيل خلف رموز غير مسماة.
- نافذة الملف تعرض الحالة والمساحة المنزلة والسرعة والوقت المتبقي ودعم الاستكمال.
- زر Background يغلق نافذة التقدم فقط. الملف المكتمل يتيح Open file وOpen folder.

## حدود التنفيذ

لا تستأنف بيانات محفوظة إذا لم تعد هوية الملف قابلة للتحقق. قد تقل الاتصالات عن العدد المطلوب تبعًا لحجم الملف وقيود الخادم. ملف جزئي محفوظ بعد خطأ يبقى لإعادة المحاولة. تغيير اسم تنزيل بدأ بالفعل غير متاح حاليًا لتجنب فصل بياناته الجزئية عن هويته.

## حالة التحقق

نجح بناء وربط تطبيق Windows، وتمت مراجعة صور الواجهة الرئيسية وفورم الإضافة ونافذة التقدم. الإصدار منشور كمعاينة. لم تُضف أو تُشغّل اختبارات سلوكية جديدة في هذه الجولة. نجاح البناء وحده لا يثبت سلامة كل حالات الشبكة والاستكمال.
