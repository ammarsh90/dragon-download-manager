# Application artwork

The master artwork is `src/resources/logo/dragon-master.png`, generated using
the built-in image generation tool. The SVG files embed this raster artwork;
they are compatibility wrappers, not hand-drawn vector originals.

Run `python tools/generate_brand_assets.py` with Pillow installed to regenerate
the PNG sizes, Windows ICO, portable icon and installer banners.

Generation brief: one professional black-and-gold desktop application icon,
with a Chinese dragon featuring antlers, flowing whiskers and a coiled
serpentine body surrounding a bold downward download arrow and tray.
Premium gold shading, strong silhouette, no lettering, watermark or mockup.
