Connect Dragon

Windows installer

Install Dragon Download Manager 1.3 or newer. The installer registers the native connection for Chrome, Edge and Firefox.

Chrome / Edge

  1. Open chrome://extensions or edge://extensions.
  2. Enable Developer mode.
  3. Choose Load unpacked and select the browser-extension/chromium folder inside the Dragon installation.
  4. Open the Dragon toolbar popup. It should say Connected.

Portable installation

Run register-browser.ps1 from the extracted application folder using PowerShell. It registers only this Windows user's Dragon native-host keys. Keep the application in that location or register it again after moving it.

Firefox development build

Open about:debugging, choose This Firefox → Load Temporary Add-on, and select browser-extension/firefox/manifest.json. This development add-on must be reloaded after restarting Firefox. Permanent Firefox installation requires Mozilla signing.

What is captured?

Direct GET downloads over HTTP or HTTPS. POST responses, blob/data URLs, private downloads and browser-blocked downloads remain with the browser. The browser copy is cancelled only after Dragon confirms that its queue was saved. Keep in queue leaves the received file paused in Dragon.

Session cookies

If enabled, only cookies matching the captured URL are sent to your local Dragon process. They are held in that job's network cookie jar and are not stored with the queue. Protected downloads resumed after restarting Dragon may need to be sent again from the browser.
